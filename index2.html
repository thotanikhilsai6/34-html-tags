34 HTML TAGS

  • DOCTYPE
    •


    Syntax: <!DOCTYPE html>
    Use: To Define The Document Type And Version Of HTML.
    Example: <!DOCTYPE html>

  • HTML
    •


    Syntax: <html></html>
    Use: To Define The Root Of An HTML Document. All other HTML elements are placed inside it.
    Example: <html>.....</html>

  • HEAD
    •


    Syntax: <head></head>
    Use: Contains information about the webpage that is not displayed directly, such as the title, CSS, and metadata.
    Example:
    <head>
        <title>My Website</title>
    </head>

  • TITLE
    •

    TAG 4 - TITLE
    Syntax: <title></title>
    Use: Sets the title of the webpage shown on the browser tab.
    Example: <title>Basic HTML Tags</title>

  • BODY
    •

    TAG 5 - BODY
    Syntax: <body></body>
    Use: Contains all the visible content of the webpage, such as text, images, links, tables, etc.
    Example:
    <body>
        <h1>HTML Tags</h1>
        <p> Basic HTML tags explanation. </p>
    </body>

  • Heading Tags
    •

    TAG 6 - Heading Tags (<h1> to <h6>)
    Syntax: <h1></h1> ... <h6></h6>
    Use: Defines headings of different levels, with h1 being the highest and h6 the lowest.
    Example:
    <h1>Main Heading</h1>
    <h2>Sub Heading</h2>
    <h3>Section Heading</h3>
    <h4>Small Heading</h4>
    <h5>Smaller Heading</h5>
    <h6>Smallest Heading</h6>

  • Paragraph Tag
    •

    TAG 7 - Paragraph Tag
    Syntax: <p></p>
    Use: Creates a paragraph of text, separating it from other content with spacing before and after.
    Example:
    <p>This is a paragraph of text.</p>

  • Line Break Tag
    •

    TAG 8 - Line Break Tag
    Syntax: <br>
    Use: Moves the text to the next line without starting a new paragraph. It is an empty tag and does not require a closing tag.
    Example:
    <p> This is the first line. <br> This is the second line. </p>

  • Horizontal Line Tag
    •

    TAG 9 - Horizontal Line Tag
    Syntax: <hr>
    Use: Draws a horizontal line across the page, often used to separate sections.
    Example:
    <p>This is the first paragraph.</p>
    <hr>
    <p>This is the second paragraph.</p>

  • Hyperlink Tag
    •

    TAG 10 - Hyperlink Tag
    Syntax: <a href="URL">Link Text</a>
    Use: Creates a clickable link that navigates to another webpage or resource.
    Example:
    <a href="https://www.example.com"> Visit Example </a>

  • Image Tag
    •

    TAG 11 - Image Tag
    Syntax: <img src="image.jpg" alt="Description">
    Use: Inserts an image into the webpage.
    Example:
    <img src="image.jpg" alt="A beautiful landscape">

  • Unordered List Tag
    •

    TAG 12 - Unordered List Tag
    Syntax: <ul><li>Item 1</li></ul>
    Use: Creates an unordered bullet list of items.
    Example:
    <ul>
        <li>Item 1</li>
        <li>Item 2</li>
    </ul>

  • Ordered List Tag
    •

    TAG 13 - Ordered List Tag
    Syntax: <ol><li>Item 1</li></ol>
    Use: Creates an ordered list of items, typically displayed with numbers.
    Example:
    <ol>
        <li>Item 1</li>
        <li>Item 2</li>
    </ol>

  • List Item Tag
    •

    TAG 14 - List Item Tag
    Syntax: <li>Item</li>
    Use: Defines an individual item within an ordered or unordered list.
    Example:
    <ul>
        <li>First Item</li>
        <li>Second Item</li>
    </ul>

  • Table Tag
    •

    TAG 15 - Table Tag
    Syntax: <table></table>
    Use: Creates a table to organize data in rows and columns.
    Example:
    <table>
    <tr>
    <th>Row 1, Cell 1</th>
    <th>Row 1, Cell 2</th>
    </tr>
    <tr>
    <td>Row 2, Cell 1</td>
    <td>Row 2, Cell 2</td>
    </tr>
    </table>

  • Table Row Tag
    •

    TAG 16 - Table Row Tag
    Syntax: <tr></tr>
    Use: Creates a row in a table.
    Example:
    <tr> <td>Cell 1</td> <td>Cell 2</td> </tr>

  • Table Data Tag
    •

    TAG 17 - Table Data Tag
    Syntax: <td></td>
    Use: Defines a cell in a table.
    Example:
    <tr> <td>Cell 1</td> <td>Cell 2</td> </tr>

  • Table Header Tag
    •

    TAG 18 - Table Header Tag
    Syntax: <th></th>
    Use: Defines a header cell in a table.
    Example:
    <tr> <th>Header 1</th> <th>Header 2</th> </tr>

  • Form Tag
    •

    TAG 19 - Form Tag
    Syntax: <form action="URL" method="method"></form>
    Use: Creates a form for users to input data.
    Example:
    <form action="submit.php" method="post">
        <label for="name"> Name: </label>
        <input type="text" id="name" name="name">
        <input type="submit" value="Submit">
    </form>

  • Input Tag
    •

    TAG 20 - Input Tag
    Syntax: <input type="type" name="name" value="value">
    Use: Creates an input field for users to enter data.
    Example:
    <input type="text" name="username" value="">

  • Label Tag
    •

    TAG 21 - Label Tag
    Syntax: <label for="id">Label Text</label>
    Use: Displays a label for an input field.
    Example:
    <label for="username"> Username: </label>

  • Button Tag
    •

    TAG 22 - Button Tag
    Syntax: <button type="type">Button Text</button>
    Use: Creates a clickable button.
    Example:
    <button type="button"> Click Me </button>

  • Text Area Tag
    •

    TAG 23 - Text Area Tag
    Syntax: <textarea></textarea>
    Use: Creates a multi-line text input field.
    Example:
    <textarea name="message" rows="5" cols="40"> </textarea>

  • Select Tag
    •

    TAG 24 - Select Tag
    Syntax: <select name="name"></select>
    Use: Creates a dropdown list for users to select an option.
    Example:
    <select name="country">
        <option value="us"> United States </option>
        <option value="ca"> Canada </option>
    </select>

  • Option Tag
    •

    TAG 25 - Option Tag
    Syntax: <option value="value"> Option Text </option>
    Use: Defines an option within a select dropdown.
    Example:
    <option value="us"> United States </option>

  • Bold Text Tag
    •

    TAG 26 - Bold Text Tag
    Syntax: <b></b>
    Use: Makes the text bold.
    Example:
    <b> This text is bold. </b>

  • Strong Tag
    •

    TAG 27 - Strong Tag
    Syntax: <strong></strong>
    Use: Makes the text strong, usually displayed as bold.
    Example:
    <strong> This text is strong. </strong>

  • Italic Text Tag
    •

    TAG 28 - Italic Text Tag
    Syntax: <i></i>
    Use: Makes the text italic.
    Example:
    <i> This text is italic. </i>

  • Underline Text Tag
    •

    TAG 29 - Underline Text Tag
    Syntax: <u></u>
    Use: Underlines the text.
    Example:
    <u> This text is underlined. </u>

  • Highlight Text Tag
    •

    TAG 30 - Highlight Text Tag
    Syntax: <mark></mark>
    Use: Highlights the text.
    Example:
    <mark> This text is highlighted. </mark>

  • Subscript Tag
    •

    TAG 31 - Subscript Tag
    Syntax: <sub></sub>
    Use: Displays text as subscript.
    Example:
    H<sub>2</sub>O

  • Superscript Tag
    •

    TAG 32 - Superscript Tag
    Syntax: <sup></sup>
    Use: Displays text as superscript.
    Example:
    x<sup>2</sup>

  • Division Tag
    •

    TAG 33 - Division Tag
    Syntax: <div></div>
    Use: Groups block-level elements. Commonly used for page layout and styling.
    Example:
    <div>
        <h1> Division Tag </h1>
        <p> This is a paragraph inside </p>
    </div>

  • Span Tag
    •

    TAG 34 - Span Tag
    Syntax: <span></span>
    Use: Groups inline-level elements. Commonly used for styling or applying CSS to a portion of text.
    Example:
    <span style="color: red;"> This text is red. </span>
